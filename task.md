## Техническое задание

Написать погодное веб-приложение на .NET Core. Можно любые библиотеки. Нужны интерфейс и бэкенд.  
Фронтенд — **Blazor (Blazor Server)**.

### UI

- Один экран с погодной информацией:
  - текущая погода;
  - почасовая (оставшееся сегодня + все часы завтра);
  - прогноз на 3 дня.
- Состояния: загрузка, ошибка с кнопкой повторного запроса.
- Дизайн свободный, главное — ясность.

### Геолокация и запросы

- Город зафиксирован: **Москва**.
- Данные из WeatherAPI:

```
http://api.weatherapi.com/v1/current.json?key=...&q=LAT,LON
http://api.weatherapi.com/v1/forecast.json?key=...&q=LAT,LON&days=3
```
