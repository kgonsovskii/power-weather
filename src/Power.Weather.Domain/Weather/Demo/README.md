# Demo FaultArm

Классы в этой папке (`IWeatherApiFaultArm`, `WeatherApiFaultArm`, `NullWeatherApiFaultArm`) нужны **только для демонстрации** на тестовом/интервью-задании.

Они позволяют кнопкой «Refresh with API error» один раз «сломать» следующий HTTP-запрос к WeatherAPI (невалидный ключ), чтобы показать экран ошибки и повторный запрос. На следующий обычный refresh переключатель сам сбрасывается.

Это **не** часть прод-контракта `IWeatherProvider` и не бизнес-логика прогноза. В реальном продукте такой код обычно удаляют или выносят за feature-flag / `#if DEBUG`.
